# Habilidades (skills) de blog e SEO instaladas neste projeto

Copiadas de repositórios abertos (licença MIT, arquivos de licença nesta pasta):
- AgriciDaniel/claude-blog: blog, blog-analyze, blog-audit, blog-write, blog-rewrite, blog-factcheck, blog-seo-check, blog-schema, blog-outline, blog-brief
- AgriciDaniel/claude-seo: seo-content, seo-technical, seo-schema
- blader/humanizer: humanizer (feito para inglês; use com cuidado em português)

Como usar no Claude Code, dentro desta pasta: peça, por exemplo, "audite o blog" (blog-audit), "analise este artigo" (blog-analyze) ou "revise a qualidade e o E-E-A-T" (seo-content).

Auditoria rápida do site inteiro, sem instalar nada: rode `npm run build` e depois `python3 scripts/auditoria-seo.py`.
